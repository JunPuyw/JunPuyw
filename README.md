## 👨‍💻 Executive Summary

> *"Systems Mind — Building high-performance, scalable web applications and AI platforms with purposeful engineering and meticulous attention to detail."*

I am a **Full Stack Developer** with nearly 2 years of professional software engineering experience specializing in modern web applications, high-throughput backend services, and generative AI platforms. I take pride in taking ideas from architectural diagrams to rock-solid production code.

- ⚙️ **Backend & Systems Engineering:** High-performance RESTful APIs and microservices using **Golang (Fiber v3)** and **Laravel (PHP)**; asynchronous queue execution, WebSocket realtime engines, and relational/NoSQL schema optimization.
- 🎨 **Modern Frontend & Creative UI:** Building responsive, accessible, and reactive user experiences using **React**, **Next.js (App Router)**, **Angular**, and **Tailwind CSS**, with stateful canvas builders powered by **React Flow**.
- 🤖 **AI Platform & Workflow Integration:** Designing visual node-based AI workflows (similar to n8n), LLM prompts/tool integrations, credit tokenomics, and distributed asynchronous media processing queues.
- 🚢 **DevOps & Cloud Deployment:** Containerized services with **Docker**, multi-service setups, Nginx reverse proxy, SSL management, Linux VPS operations, and CI/CD automation.
